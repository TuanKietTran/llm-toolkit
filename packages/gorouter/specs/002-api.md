# 002 HTTP API

| Method | Path | Format | Notes |
|--------|------|--------|-------|
| POST | `/v1/chat/completions` | OpenAI | stream via `"stream": true` |
| POST | `/v1/messages` | Anthropic | for Claude Code etc. |
| POST | `/v1/embeddings`, `/v1/images/generations`, `/v1/audio/speech` | OpenAI (JSON) | forwarded to `openai`-type providers, model rewritten, combo/fallback/quota apply |
| POST | `/v1/audio/transcriptions`, `/v1/audio/translations` | OpenAI (multipart) | same; multipart body re-encoded with the upstream model |
| GET | `/v1/models` | OpenAI | providers' models + combos + aliases |
| GET | `/health` | JSON | unauthenticated |
| GET | `/admin/usage` | JSON | per `provider/model` stats |
| GET | `/admin/status` | JSON | providers, cooldowns, combos (see 010) |
| GET/PUT | `/admin/config` | JSON | hot-reload (see 008) |
| GET | `/dashboard/` | HTML | admin UI (see 010) |
| GET | `/oauth/callback` | HTML | OAuth redirect target (see 009) |

- REQ-002-1: Request `model` may be `provider/model`, a bare model listed by providers, an alias, or a combo.
- REQ-002-2: If `api_keys` is non-empty every endpoint except `/health` requires `Authorization: Bearer <key>` or `x-api-key`. Empty list = open (local use).
- REQ-002-3: Errors use the client's native error shape. Status mapping: unknown model 404, bad request 400, auth 401, non-retryable upstream 4xx passed through, exhausted fallbacks 502/429/5xx (last upstream status class), client disconnect 499.
- REQ-002-5: Raw endpoints only route to `openai`-type providers; the body/response (including binary audio) is passed through unchanged. Embeddings usage is read from `usage.prompt_tokens`.
- REQ-002-4: Successful responses carry `X-Gorouter-Target: provider/model`, with `@account` appended for non-default accounts.
- REQ-002-6: Successful routed responses carry `X-Gorouter-Attempts: N`, the number of upstream targets tried (including the successful target). This makes fallback behavior observable without exposing response bodies or credentials.
